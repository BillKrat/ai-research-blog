A host name decides whose site and data a visit reaches. Add a site's temporary address (for example http://your-account-site1.atempurl.com; the scheme is ignored) or another domain to the tenant it should show. The API then also lets that site's browser call it. A host name can belong to only one tenant. A change works straight away.
