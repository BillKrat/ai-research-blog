# ai-research-blog

Angular + ASP.NET Core (MCP Host) + Aspire. See [docs/SESSION_HANDOFF.md](docs/SESSION_HANDOFF.md)
for the full architecture, decisions, and current status before touching anything here.

All components deployed to a [SmarterASP plan](https://www.smarterasp.net/index?r=100827593) ($38/qtr) via GitHub actions.  Currently [www.global-webnet.com](https://www.global-webnet.com)
with an Angular client [not shown below] and its [https://api.global-webnet.com](https://api.global-webnet.com/api/health) are deployed.
[AdventuresOnTheEdge.net](https://AdventuresOnTheEdge.net) is the legacy [BlogEngine.net fork](https://github.com/BillKrat/ai-research-blog) that will be replaced with ai-research-blog open source project.
