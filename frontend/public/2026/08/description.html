Vocabulary / Property

description

Associates a resource with explanatory text.

Canonical URI

https://blogresearch.net/2026/08/description

Use

Use a text value to explain a person, data set, schema, or other application resource. Keep it suitable for display in documentation or an administrative interface.

Example

subject:   https://blogresearch.net/2026/08/database-schema/example
predicate: https://blogresearch.net/2026/08/description
object:    The schema for the example data set.
