Vocabulary / Property

database-schema

Associates a data set with the schema that describes its structure.

Canonical URI

https://blogresearch.net/2026/08/database-schema

Use

The subject is normally a DataSet and the object is a resource whose type is DatabaseSchema. This is a relationship predicate, not the schema class itself.

Example

subject:   https://blogresearch.net/2026/08/dataset/example
predicate: https://blogresearch.net/2026/08/database-schema
object:    https://blogresearch.net/2026/08/database-schema/example
