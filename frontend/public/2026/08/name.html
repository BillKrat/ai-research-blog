Vocabulary / Property

name

Associates a resource with a short, human-readable name.

Canonical URI

https://blogresearch.net/2026/08/name

Use

Use a text value for display, navigation, and basic identification. The name is not a unique identifier; the subject URI remains the stable identifier.

Example

subject:   https://blogresearch.net/2026/08/dataset/example
predicate: https://blogresearch.net/2026/08/name
object:    Example data set
