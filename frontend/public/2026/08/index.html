Application vocabulary

A small, application-owned vocabulary for identifying resources and facts in the triple store.

These terms use HTTPS URIs rooted at https://blogresearch.net/2026/08/. The vocabulary is intentionally simpler than a full RDF or RDFS ontology: the application stores subject, predicate, and object values as text.

Classes

  • PersonA person or identity represented by the application.
  • DataSetA named collection of data.
  • DatabaseSchemaThe structure that describes a database or data set.

Properties

  • typeAssociates a resource with a class.
  • nameAssociates a resource with a human-readable name.
  • descriptionAssociates a resource with explanatory text.
  • database-schemaAssociates a data set with its schema.
