Vocabulary / Class

Person

A person or identity represented by the application.

Canonical URI

https://blogresearch.net/2026/08/Person

Use

Use this URI as the object of type when a subject represents a person. A person instance should have its own URI, such as https://blogresearch.net/2026/08/person/application-owner.

Example

subject:   https://blogresearch.net/2026/08/person/application-owner
predicate: https://blogresearch.net/2026/08/type
object:    https://blogresearch.net/2026/08/Person
