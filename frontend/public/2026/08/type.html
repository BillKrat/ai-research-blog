Vocabulary / Property

type

Associates a resource with one of the application vocabulary classes.

Canonical URI

https://blogresearch.net/2026/08/type

Use

The object should normally be one of Person, DataSet, or DatabaseSchema. This application-owned term is the simplified equivalent of RDF's rdf:type.

Example

subject:   https://blogresearch.net/2026/08/dataset/example
predicate: https://blogresearch.net/2026/08/type
object:    https://blogresearch.net/2026/08/DataSet
