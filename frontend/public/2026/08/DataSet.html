Vocabulary / Class

DataSet

A named collection of data managed or referenced by the application.

Canonical URI

https://blogresearch.net/2026/08/DataSet

Use

Use this URI as the object of type for a data collection. A data set instance should have its own URI, such as https://blogresearch.net/2026/08/dataset/example.

Example

subject:   https://blogresearch.net/2026/08/dataset/example
predicate: https://blogresearch.net/2026/08/type
object:    https://blogresearch.net/2026/08/DataSet
