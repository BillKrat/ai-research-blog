Vocabulary / Class

DatabaseSchema

A resource describing the structure and fields of a database or data set.

Canonical URI

https://blogresearch.net/2026/08/DatabaseSchema

Use

Use this URI as the object of type for a schema resource. The schema itself should have its own URI, such as https://blogresearch.net/2026/08/database-schema/example.

Example

subject:   https://blogresearch.net/2026/08/database-schema/example
predicate: https://blogresearch.net/2026/08/type
object:    https://blogresearch.net/2026/08/DatabaseSchema
